# 한국어 번역 감수 원칙

## 정본과 목표

- 독일어 eKGWB 스냅샷을 정본으로 삼는다.
- 현대 한국어 출판 번역을 참조하거나 복제하지 않는다.
- 문자 대응보다 논증의 방향, 문장 호흡, 반어와 거리 두기를 함께 보존한다.
- 한국어만 읽어도 자연스럽되, 독일어의 핵심 개념과 수사적 강도는 약화하지 않는다.
- 시대적·논쟁적 표현은 미화하거나 검열하지 않고 번역하되, 오해에 문헌적 배경이 필요한 경우 각주로 구분한다.

## 기본 용어

- `Wille zur Macht`: 힘에의 의지
- `Mitleid`: 연민
- `Ressentiment`: 르상티망
- `Umwerthung`: 가치 전도
- `Übermensch`: 초인
- `décadence`: 데카당스 또는 문맥상 쇠퇴. 개념어로 쓰일 때는 데카당스를 우선한다.
- `Geist`: 정신. 지성·기지의 뜻이 전면에 나올 때만 문맥에 맞게 조정한다.
- `Trieb`: 충동 또는 본능. 생리적·유형론적 논의에서는 본능을 우선한다.
- `Selbst-Ueberwindung`: 자기 극복
- `Ewige Wiederkunft`: 영원회귀
- `Nachlass`: 유고. 1885–1888년 자료는 《권력 의지》의 사후 편집 배열이 아니라 비평판 단편 번호로 인용한다.

새 코퍼스에서 `draft`는 Codex가 독일어 원문과 같은 절의 문맥을 읽고 직접 만든 초벌 번역만을 뜻한다. 외부 기계번역 API나 현대 한국어 출판 번역은 사용하지 않는다. `reviewed`는 아래 감수 기준을 다시 모두 통과한 뒤에만 부여한다.

## 레코드 감수 기준

`reviewed`는 다음을 모두 확인한 레코드에만 부여한다.

1. 독일어 원문과 한국어를 직접 대조했다.
2. 같은 절의 앞뒤 문맥을 확인했다.
3. 주어·부정·비교·인과·인용의 범위를 확인했다.
4. 핵심 용어가 작품 전체의 용례와 일치한다.
5. 한국어 어순과 호흡을 다듬고 불필요한 번역투를 제거했다.
6. 고유명사, 외국어, 고전 인용, 말장난 때문에 독해가 막히면 각주를 작성했다.

## 각주 형식

각주는 번역 캐시의 `footnotes` 배열에 둔다. 본문을 대신 해석하거나 감상을 강요하지 않고, 확인 가능한 배경과 번역상의 쟁점만 짧게 설명한다.

```json
{
  "label": "하이퍼보레아인",
  "text": "그리스 신화에서 북풍 보레아스 너머에 산다고 여겨진 행복한 민족. 여기서는 현대 유럽의 가치에서 벗어난 자들을 가리키는 자기 명명으로 쓰인다."
}
```
